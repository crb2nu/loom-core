- Mills' `mr` stage now records the created merge request onto the linked plan's slice (`pkg/mills/pipeline/plan_mr_ref.go`, `pkg/mills/takeup/mr_ref_recorder.go`, `pkg/mills/clients/plan_takeup.go`). Previously a plan-linked item's slice kept `mr_ref` empty unless the spawned agent remembered to call `agent_plan_slice_update`, so the take-up reconciler had nothing to poll, the plan never walked to `merged`, and the J2 pattern harvest never fired. Attribution is exact for emitter-minted `psl-*` items, falls back to the single unrecorded slice or the best file-overlap match, and leaves a decision note rather than guessing when a multi-slice plan is ambiguous. The write is best-effort and never fails the `mr` stage.
