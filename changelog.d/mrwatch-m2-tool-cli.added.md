- **Branch-MR awareness surfaces: `loom agent mr-status` CLI + `agent_mr_status` MCP tool** (mrwatch M2) (`cmd/loom/cmd_agent_mrstatus.go`, `cmd/loom/cmd_agent.go`, `pkg/agentcontext/svc_mrwatch.go`, `pkg/agentcontext/svc_bridge_wrappers.go`, `pkg/agentcontext/service.go`, `cmd/mcp-agent-context/tools_bridge.go`, `cmd/loom/proxy_tool_filter.go`, `pkg/generator/platform_profiles.yaml`): agents can now query the HUD mrwatch registry (slice M1) for the classified stall status of every open merge request on a branch. The `loom agent mr-status --branch <b> [--repo <r>]` CLI supports `--json` (raw HUD payload), `--brief` (one line per MR: `!IID <state> <reason> <web_url>`), and `--delta` (with `--brief`, print only when the state hash changed vs. the cache under `~/.loom/mrwatch/<sanitized-branch>.state`, else exit 0 silently) — built for delta-gated `UserPromptSubmit`/`BeforeModel` hooks. It defaults `--branch` to the cwd's current git branch and is hook-safe: an unreachable HUD exits 0 with no output (a JSON error object + exit 1 only under `--json`). The `agent_mr_status` MCP tool in mcp-agent-context takes `{branch, repo?}`, calls the same HUD endpoint via the existing `AGENT_CONTEXT_HUD_URL` → `LOOM_HUD_URL` → `http://127.0.0.1:3333` chain, and returns `available=false` (never a tool error) when the HUD is down. The tool is added to the llm-core proxy priority tail with the cap bumped 164 → 165 (a single tail addition without the bump would silently displace the last ICC/PM entry).
