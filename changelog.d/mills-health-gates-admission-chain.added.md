- **Bring the Mills infrastructure admission chain online end to end** (`pkg/mills/gates/storage_evaluator.go`, `pkg/mills/gates/local_config.go`, `cmd/loom-mills-operator/health_gates.go`, `pkg/mills/runner/classification_policy.go`): the gate interfaces had no production implementation, so `pipeline.Runner.HealthGates` was never set, `runPreflight` returned immediately, and the HUD tile always rendered its fail-closed default. A composite `StorageHealthEvaluator` now probes the store's filesystem (capacity, inodes, read-only remount, a real write, and a store ping), the MCP hub, and an optional vector DB, each stamped with its own observation time; a `LocalConfigPreflight` checks the store directory and repo root. The operator wires one evaluator into the pipeline preflight, the council planning policy (`council.ApplyClassificationPolicy`, previously uncalled anywhere), and a new `health_gates` key on `GET /api/mills/status`. `LOOM_MILLS_HEALTH_GATES` selects `off`, `observe` (default — publishes the verdict without blocking), or `enforce`.

- **Fix a fail-closed gate that would have blocked every pipeline** (`pkg/mills/gates/gate_runner.go`): `GateRunner.Run` sampled the clock before invoking the storage evaluator, so evidence stamped by any live probe landed in the future relative to it and `EvaluateHealthSnapshot` rejected it as stale — reporting the contradictory "age 0s exceeds 5m0s". Only fakes returning fixed past timestamps survived. The evidence is now judged at an instant sampled after it is collected.

- **Map persisted CI failure classes onto the incident taxonomy** (`pkg/mills/council/brief.go`): `canonicalClassifiedCIFailureClass` returned raw `FailureClass`/`EscalationClass` strings, producing values like `code` and `infra` that match no `CIIncidentClass` constant, so every downstream taxonomy comparison silently missed. Both the store spelling (`infrastructure`, `configuration`) and the pipeline spelling (`infra`, `config`) now resolve to real constants, and an unrecognized value falls back to `unclassified` rather than leaking through.
