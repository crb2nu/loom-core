- Changed `mcp-devbox` K8s sandboxes to mount a shared Go build/module/lint cache claim (`DEVBOX_K8S_GO_CACHE_PVC`, verified at start and skipped with a WARN when the claim is missing) so a quality gate no longer recompiles the whole dependency tree in every fresh pod; made the quality gate budgets configurable (`DEVBOX_QUALITY_GATE_CHECK_TIMEOUT_SEC`, `DEVBOX_QUALITY_GATE_TEST_TIMEOUT_SEC`, hub default 1200s for the test commands) and, when a check times out, the output tail now names the budget and the sandbox's cgroup CPU throttling so a starved container is distinguishable from slow tests.
