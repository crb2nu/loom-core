- Manual operator overrides are now labeled events in the Mills events store: pipeline resume, force-escalate and manual start/requeue (`cmd/loom-mills-operator/handlers_pipeline.go`) plus workflow-run pause, resume and fail (`cmd/loom-mills-operator/handlers_workflow.go`) append actor `operator.manual`, kind `operator.override.<action>` and payload `{action, subject_kind, subject_id, reason?}` via the shared best-effort helper in `cmd/loom-mills-operator/handlers_helpers.go`. Overrides are the factory's supervised training labels, so every mutation now leaves a trace an autonomy review can read; the reason is optional (`?reason=` or the handler's existing JSON body) and an append failure is logged without failing the override itself.
