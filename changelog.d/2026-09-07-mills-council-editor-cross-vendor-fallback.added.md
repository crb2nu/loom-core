Mills council editor chain gains a cross-vendor hop: primary → the other frontier provider → local flexinfer. An `anthropic` editor now falls back to OpenAI (`gpt-5.5` by default, pin via `council.ensemble.editor_fallback: { model, backend }`, opt out with `backend: none`) before the local editor, so a vendor-scoped failure — the 2026-09-07 Anthropic billing hold that errored three consecutive council runs after ~$1.7 of reviewer spend each — no longer hard-fails the run while the other vendor's key sits idle. The hop is skipped at build time when that key is absent, and fallback log lines now name both editors.
