- Fixed `mcp-devbox` giving every Mills pipeline run the same sandbox pod: the agent part of a sandbox name was truncated to its first twelve characters, so `loom-mills-operator-<run>` ids all became `devbox-loom-core-loom-mills-o` and concurrent runs shared one CPU-throttled pod whose every "restart" killed the other runs' quality gates. Long agent ids now render as a short prefix plus a five-hex digest of the whole id (deterministic, still within the twelve-character budget); short ids such as `claude-code` are unchanged. The K8s sandbox image builds also get 2 CPU (was 500m) so buildah builds stop stalling the tests stage.
