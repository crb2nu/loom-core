- HUD Mills proxy: a caller that holds the operator admin token can send it as `X-Loom-Operator-Token` on `/api/mills/*` mutations and it becomes the upstream Bearer, replacing the HUD's own copy. Before, the HUD overwrote every caller's Authorization with its own (possibly stale) `LOOM_MILLS_OPERATOR_TOKEN`, so a valid token matching the cluster secret still drew `401 invalid admin token` from the operator (2026-09-12, filing backlog items through `localhost:3333`). Browser and mobile Authorization headers are still replaced, as before.
