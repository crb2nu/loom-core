- **mills: human-gated queue holds are no longer counted as reconciler "skipped" ticks** (`pkg/mills/reconciler.go`, `pkg/mills/metrics.go`, `cmd/loom-mills-operator/handlers_status.go`): `tryStart` now returns a distinct `held_human` decision when an item's effective policy requires human review (item `require_human_review` or the per-repo override, both resolved by the new `Policy.RequiresHumanReview`), `TickResult` carries a `HeldHuman` counter, and `mills_reconciler_ticks_total` emits `outcome="held_human"` for ticks whose only unstarted work is human-gated. `outcome="skipped"` is kept for the policy-disabled / autonomy-blocked early returns and genuine per-item skips (claim conflicts, cross-repo gate, workflow holds). On 2026-09-07 the single queued item `bl-mcpo-sse-removal-endgame-20260829` carried `require_human_review: true`, so 568/568 ticks over 9h read as "skipped" — indistinguishable from a dispatch outage. `GET /api/mills/status` also reports `queue_held_human` beside `queue_depth` so an operator can see the queue is waiting on a hand-off rather than on the reconciler. The `reconciler.tick` event and the scheduler debug log carry the new `held_human` count.
