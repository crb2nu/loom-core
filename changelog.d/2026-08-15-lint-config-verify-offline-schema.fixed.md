- The blocking `lint` job no longer reaches the public internet: `golangci-lint config verify` was silently fetching its JSON schema from `golangci-lint.run` at runtime, so any pipeline could go red on a network blip (pipeline 23729 job 235686 timed out on that fetch with no Go or config change in the MR). The v2.8 schema is now vendored at `ci/golangci.v2.8.jsonschema.json` and passed via `--schema`; the filename is derived from the binary version so a golangci-lint bump without re-vendoring fails with an explicit message. `check_ci_external_endpoints` gained a rule that flags both a literal `golangci-lint.run` reference and a bare `config verify`, so the class cannot quietly return.
