- **Stale "Pipeline Stuck" alerts now clear themselves** (`internal/hud/alerting/engine.go`): the HUD alert engine had no resolution path, so a fired stuck alert sat in `GET /api/alerts` forever — its embedded `PipelineRef` is a snapshot from fire time, so pipelines that passed days ago still read as "running". `Evaluate` now resolves a stuck alert as soon as its pipeline stops running (terminal status, or gone from the active list), stamps `resolved_at`, refreshes the status snapshot, and `ListAlerts` withholds resolved alerts from the active view every HUD and mobile surface reads. The default stuck threshold also moves from 30m to 60m: healthy loom-core pipelines routinely run 30–39 minutes, so the old bound flagged green runs — one alert fired four seconds before its pipeline passed.
