- **Move the spawn Go-cache claim out of `k8s/base` so it lands in the namespace spawn pods can mount** (`k8s/base/kustomization.yaml`, `k8s/base/servers/mobile-hud/deployment.yaml`, manifest relocated to platform/gitops `k3s/devbox/`): the PVC added alongside the mobile-hud manifests declared `namespace: devbox`, but the `loom-hub-servers` Flux Kustomization pins `spec.targetNamespace: loom-hub`, which overrides the namespace of every resource in that tree — so the claim was created as `loom-hub/spawn-go-cache`, and a namespace-scoped PVC is unmountable by the spawn pods that run in `devbox`. With `SPAWN_GO_CACHE_PVC` already live on the deployment, the next spawn would have wedged `Pending` on a missing claim (caught before any spawn hit it). The claim now lives in the gitops `k3s/devbox` kustomization (`namespace: devbox`, no Flux override — gitops!496) and Flux prune removes the stray `loom-hub` volume. The `namespace:` field is decorative in this tree: any resource the SPAWN side must reach belongs in the devbox kustomization, not here.
