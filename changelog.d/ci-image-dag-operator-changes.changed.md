CI: the three image jobs now declare a `needs:` DAG on their real gates (lint, vet, unit, integration, reliability, enterprise-smoke, gosec, govulncheck, frontend) instead of waiting for the whole test stage, so a post-merge image lands ~10 minutes after a validated-tree merge instead of ~40; `test:race`, `test:benchmark` and `build:binaries` keep running on main in parallel. `build:binaries` gains the validated-tree skip. `build:image:loom-mills-operator` only rebuilds (and Flux only rolls the operator) when a path in the operator binary's import footprint changes, with `scripts/ci/check_operator_image_changes.sh` (run in `vet`) failing CI if that list ever stops covering a real dependency.
