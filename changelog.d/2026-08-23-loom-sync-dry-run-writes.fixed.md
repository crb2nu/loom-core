- **`loom sync --dry-run` no longer writes** (`cmd/loom/cmd_sync_sync.go`): the flag was declared and covered by a registration test, but `runSyncCmd` only ever forwarded it to the `--all-projects` propagation — the `SyncToHome`/`SyncAll` path ignored it, so `loom sync <profile> --dry-run` synced to home (and with `--regen`, regenerated into the repo) while advertising "show what would change without writing". Dry runs now report the pending drift using the same machinery as `loom sync status` and return before any write. Found during weekly instruction-surface maintenance, where probing three profiles for drift silently re-synced them.
