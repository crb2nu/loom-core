- Mills tests stage: the devbox quality gate is no longer cut off by the MCP hub client's 10-minute per-call default. `MCPHubClient.CallToolWithTimeout` threads an explicit round-trip cap and `DevboxClient` calls the gate with `GateTimeout` (default 60m, env `LOOM_MILLS_DEVBOX_GATE_TIMEOUT`), sized for fmt + lint + the declared test commands under the devbox server's own budgets (300s per check, 1200s per test command in production). Before this every gate over ten minutes died as `mcphub: recv devbox/devbox_quality_gate: read message: … i/o timeout`, burned its free transient retries, and escalated the item with the branch unvalidated.
