- loomd: three log-noise and resilience fixes from the 2026-09-10 qdrant outage and the 2026-09-09..12 daemon log. HUD monitors now back off up to a 5-minute effective interval during a sustained upstream failure, log three warnings then one "still failing" summary per five minutes, and report the outage duration on recovery (previously a 15s monitor kept polling a dead upstream every 75s and wrote ~950 identical warnings per monitor per day). A tool error envelope from agent-context is reported as the tool's failure ("agent tool X failed: …") instead of being labelled "unmarshal X result". The hub keepalive's raw-pong compatibility downgrade warns once per hub server and then logs at debug (6,179 identical warnings in three days, one per 30s ping).
