- **HUD: 9 zero-consumer HTTP routes removed** (`internal/hud/domain/{shuttle,coordinator}`). Each was verified to have no caller across `internal/hud/frontend`, `apps/loom-companion-ios`, `cmd/`, `pkg/`, and `scripts/` before deletion. Shuttle drops 6 of 7 routes — `GET /api/shuttle/capacity`, `GET /api/shuttle/recommendations`, `POST /api/shuttle/dispatch`, `GET /api/shuttle/policies`, `PUT /api/shuttle/policies`, `POST /api/shuttle/preflight` — because the surviving `GET /api/shuttle/status` snapshot already embeds capacities, recommendations, and pending-task counts, which is the only shape the HUD client (`src/lib/clients/shuttle.ts`) ever read. Coordinator drops 3 of 4 — `GET /api/coordinator/status`, `POST /api/coordinator/summarize/{session_id}`, `POST /api/coordinator/plan` — keeping `POST /api/coordinator/compress`, which `pkg/agentcontext/compaction_llm.go` calls server-to-server, and the `GET /api/coordinator/metrics` Prometheus handler.
- **HUD: the plumbing behind those routes removed with them.** `shuttle.Deps` loses `ShuttleEngine()`, `ShuttleBridge()`, and `Logger()`, with the matching `shuttleDepsAdapter` methods in `internal/hud/domain_adapters_ops.go`. `coordinator.Deps` loses `Logger()` and `BroadcastAgentEvent()`, and `CoordinatorOps` narrows from five methods to just `RunCompression` — so the domain layer no longer restates the summarizer and planner contracts it does not serve. The `coordinator.plan.complete` agent event, which only the deleted plan handler ever broadcast, is gone.
- **Left in place deliberately:** the `coordinator.plan.complete` consumers. `classifyPlanCompleteEvent` in `internal/hud/push_bridge.go` and the matching entry in the mobile event catalog (`internal/hud/domain/mobile/helpers.go`) now have no in-tree emitter, but they classify `bridge.SSEEvent` traffic that can originate outside this process, and the catalog is a wire contract the iOS companion reads.
- **Unchanged:** the engines themselves. `internal/hud/shuttle` and `internal/hud/coordinator` keep every method, including the ones now reachable only in-process or from their own tests (`Engine.GetPolicy/UpdatePolicy/PreflightCheck`, `Coordinator.Status/SummarizeSession/PlanWorkflow/RegisterPlan` and the `Planner` behind them). This slice prunes the HTTP surface only.
