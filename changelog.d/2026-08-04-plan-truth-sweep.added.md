- Added a plan-store truth sweep to agent-context: a periodic reconciler (`pkg/agentcontext/plan_reconciler.go`) that queries the HUD `mr-status` registry by slice branch and, on an explicitly merged MR, advances the slice to `merged` with an `auto-advanced: MR merged (<ref>) [plan-truth-sweep]` decision note — then walks the parent plan stepwise through the legal phase DAG to `merged` once every slice has landed. It only ever moves phases forward, skips slices without branch/MR provenance, fails open on HUD outages, stale snapshots, and absent records, and bounds each pass with a timeout. Tunable via `AGENT_CONTEXT_PLAN_RECONCILER_ENABLED` and `AGENT_CONTEXT_PLAN_RECONCILE_INTERVAL` (Go duration, default 15m); disabled entirely when no HUD base URL is configured. Adds `loom_plan_sweep_slices_advanced_total`, `loom_plan_sweep_plans_advanced_total`, and `loom_plan_sweep_errors_total` counters (`pkg/agentcontext/metrics.go`).
