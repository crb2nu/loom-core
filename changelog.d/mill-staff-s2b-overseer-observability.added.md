Mill Staff S2b overseer observability: first Prometheus metrics for the floor lane — `mills_overseer_ticks_total{agent,outcome}`, `mills_overseer_tick_duration_seconds{agent}`, `mills_overseer_actions_total{agent,action,mode}` (mode `dryrun`/`committed`/`observed`/`flagged`, mirroring the ActionRecorder contract), and `mills_overseer_suppression_active{agent}` — giving the dry-run soak durable tick evidence (the sentinel and foreman deliberately write no per-tick events). The `/api/mills/overseers` status endpoint now resolves each agent's enabled/dry-run/suppression through its registration entry instead of a hardcoded name switch, so a fourth supervisory agent can no longer silently report `enabled=false`.
