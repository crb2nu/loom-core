The WebSocket pass-through used by Mills spawn pods forwarded all tools unfiltered. `LOOM_PROXY_WS_PROFILE=<profile>` now applies `filterProxyTools` to the backend's `tools/list` response, with `LOOM_PROXY_WS_SERVER` (default `agent_context`) supplying the namespace used to match the namespaced priority patterns against the backend's un-prefixed tool names. **Default is unchanged** — no env, no filtering — because in-cluster Mills depends on the raw pass-through; a malformed or non-array result is forwarded untouched.
