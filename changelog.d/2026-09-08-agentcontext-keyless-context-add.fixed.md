- **`agent_context_add` no longer rejects every write when no embedding API key is configured** (`pkg/agentcontext/svc_context_add.go`): a Morph-era precondition returned `AGENT_CONTEXT_EMBED_API_KEY (or MORPH_API_KEY / OPENAI_API_KEY) is not set` before the embedder was consulted, even though the default flexinfer provider is a keyless in-cluster proxy and the store already falls back to deterministic vectors when embedding fails. After the hub's agent-context dropped its Morph environment (2026-09-06) the Mills escalator and every fleet agent routed through the hub lost decision and finding recording. The guard is removed; a keyless write now persists and is covered by `TestAdd_NoEmbedAPIKeyStillPersistsContext`.
