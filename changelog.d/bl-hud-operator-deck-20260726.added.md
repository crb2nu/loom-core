Operator Deck — a unified operator surface and new HUD landing view (`#operator/deck`). One page composes the work queue (plans with spin/dispatch controls, task pressure, project rollups), a live in-flight board (Mills pipeline runs, tracked MRs/CI, agent sessions grouped by conversation), and a selection-aware inspect dock (run stages/gates with requeue, live tool-call feed + context-window health, MR shepherd history, ambient context stream). Dispatch reuses the proven Plans flows (spawn / handoff / run-in-Mills). The iOS companion gains a matching Operator screen as the first tab, with the classic dashboard pushed behind its toolbar.
