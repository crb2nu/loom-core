- **mills: store DSN gains `temp_store=MEMORY` — fixes the migration-019 operator crashloop** (2026-08-01 incident). Migration 019's table rebuild (the first migration to need SQLite temp storage) failed with `SQLITE_IOERR_GETTEMPPATH` on the operator's `readOnlyRootFilesystem` — every candidate temp dir (SQLITE_TMPDIR/TMPDIR//var/tmp//tmp) is unwritable there, and only the DB PVC is mounted writable — crashlooping the operator from the first post-!1351 image writeback until a gitops rollback to the pre-019 image restored service. `temp_store(MEMORY)` in the pooled DSN removes the temp-file path entirely (Mills tables are small; memory temp storage is safe), and a regression test asserts the pragma reaches pooled connections since the container condition cannot be reproduced on a dev host. Recovery lesson encoded in the rollback MRs: the IUA suspension must land in the SAME gitops commit as an image pin, and a malformed manifest in `k3s/flux/image-automation/` takes down the entire apps kustomization build.
