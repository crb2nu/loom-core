- Lift the daemon's silent 500-tool ceiling on the aggregate tool cache. The profile library ships the built-in `full` profile capped at 500; once the fleet reached 589 tools (2026-09-12) the last 89 in source order were dropped before any proxy profile saw them, so hint-less and `--tool-profile full` clients lost whole servers and the llm-core priority list could not match tools it never received. The daemon now owns the ceiling (`context.max_tools`, default 0 = unlimited; a custom profile file still wins), and any remaining truncation names the displaced servers (`displaced="weaver=12/12 zep=3/3"`) instead of only reporting counts (`internal/daemon/tool_ceiling.go`, `internal/daemon/config.go`).
