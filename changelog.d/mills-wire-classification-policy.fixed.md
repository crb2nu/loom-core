- **Council classified planning policy is reachable instead of dead code** (`pkg/mills/runner/runner.go`, `pkg/mills/runner/classification_policy_test.go`): `council.ApplyClassificationPolicy` shipped with tests but no caller, so its evidence-driven proposal suppression and fail-closed storage-health block never ran. The council runner now applies it between the editor and artifact stages — the incident class is reduced from the brief's classified `ci_watch` failures (external only when the evidence is unanimous, so a mixed window never suppresses legitimate repository work) and the storage verdict comes from a new optional `Runner.HealthGates` preflight. Leaving `HealthGates` nil, which is what `cmd/loom-mills-operator` wires today, keeps the run byte-identical to the pre-policy path; a configured gate is fail-closed, and a gate that cannot be evaluated is logged and treated as blocked rather than failing the run.
