- Mills stage telemetry (`/api/mills/telemetry/stages`) now classifies the failure shapes that dominated the 2026-09-01 window instead of bucketing them as `other`: `sandbox_build` (devbox sandbox image still building when the tests stage's wait expired), `ci_red` (branch pipeline reached `status=failed`), and `merge_queue` (serial-queue eviction or stale merge authorization). The runner also appends the dispatcher error as a trailing `error:` line to a worker-supplied log tail, so a ci_watch poll timeout classifies as `ci_poll_timeout` rather than vanishing behind the poller's `status=running` lines.
