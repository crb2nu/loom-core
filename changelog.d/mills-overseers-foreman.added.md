Mills Overseers (slice 3): Mill Foreman. A KPI-anomaly supervisory agent on the shared overseer harness that runs four deterministic rules over the store every 15 minutes — `stuck_runs` (an active pipeline run older than `stuck_run_hours`), `throughput_collapse` (queue non-empty with zero merges across `zero_merge_hours`), `escalation_storm` (≥ `escalation_storm_24h` escalations in 24h), and `budget_burn` (1d pipeline cost / `budgets.pipeline.max_usd_per_day` ≥ `budget_burn_ratio`). Each firing anomaly is observed once per rule/UTC-day (`anomaly_opened`, cleared on recovery) and can, per its `allow` flag, file a dedup-marked GitLab issue (body composed by the judge LLM when available, deterministic template on any LLM error — an LLM outage never blocks filing), post the anomaly to the `notify.webhook_url`, and assert a TTL-bounded admission-suppression lease (60m dead-man's switch, hard-capped at one committed pause per rolling 24h read durably from events, re-asserted while the anomaly persists). Dry-run defaults ON and records plans-only with per-episode/per-day dedup. The pause lease and each rule are audited in the events table with no schema migration. Additive: `notify.WebhookHook.PostEvent` reuses the existing webhook config verbatim; foreman suppression surfaces in `GET /api/mills/overseers`.
