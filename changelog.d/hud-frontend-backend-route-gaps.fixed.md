Closed four HUD frontend/backend contract gaps found by a route audit. `GET /api/mills/cost-preview` is now proxied to the Mills operator — the frontend called it but no route was registered, so the SPA catch-all served `index.html` and the cost estimate failed to `JSON.parse` silently. `POST /api/agent/deregister` is now a real route in the fleet domain, wired to the `PresenceDeregister` bridge capability that previously only the orphan reaper could reach; `loom agent keepalive` posts there on SIGINT/SIGTERM, and its 404 was discarded, so terminated agents lingered in the fleet view until the reaper timed them out. Both the CLI and the route now share the `bridge.AgentDeregisterEndpoint` constant. The mobile companion token may now reach `GET /api/patterns` (exact path only — `POST /api/patterns/stamp` stays blocked), unblocking the iOS shift report's approved-pattern list. Finally, `/api/cache/stats` and `/api/engrams/summary` now carry a `degraded` flag on their fallback paths so clients can tell "backend unavailable" apart from a genuine zero.
