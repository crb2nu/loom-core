Mills Overseers (slice 4): HUD Overseers panel. New "Overseers" tab under Mills surfaces the supervisory agents (groomer / sentinel / foreman) that ride the guarded-auto-act harness. Each agent card shows its enable/dry-run/pause state, last tick time, and last-result counts (inspected/acted/planned/skipped/errored) with the tick note (e.g. `llm_unavailable`); a prominent warning strip calls out any live admission-suppression lease (reason + expiry). A collapsible, scrollable per-agent recent-actions log renders the last 24h of audit events (kind, subject, key payload fields like `canonical_id`/`jaccard`/`reason`). Backed by a read-through HUD proxy route `GET /api/mills/overseers` (open read, HUD admin token stripped) and a dedicated Svelte store that polls at 15s, normalises the operator payload at the fetch boundary, and degrades to a calm empty state when the operator is unconfigured (503).
