- Serial merge queue for the Mills pipeline (`merge_queue.enabled`, default off): the merge stage enqueues its CI-authorized candidate and a per-(project, target branch) processor rebases stale heads onto the exact target tip, re-proves them with a fresh pipeline, and merges one at a time — killing the `has_conflicts` MR deaths and the merge bursts that stack uncancelable main pipelines. Evictions (`ci_red`, `rebase_conflict`, `queue_full`, …) escalate through the existing path with distinct reasons; queue state is durable and restart-safe, with depth/wait/eviction metrics and a `merge_queue` block in run detail.
