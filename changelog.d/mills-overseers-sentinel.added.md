Mills Overseers (slice 2): Deployment-Health Sentinel. Probes the operator's hard dependencies (FlexInfer, GitLab, HUD, Loki — built only for what the deployment configures) every 5 minutes; `trips_to_open` consecutive failures open an incident that can file a dedup-marked GitLab issue (auto-closed on recovery) and — when `allow.suppress_admission` — assert a TTL-bounded suppression lease over automated work admission. The lease is re-asserted per tick and self-expires (dead-man's switch), never touches the kill-switch machinery, and leaves HTTP `admit` endpoints open for humans. Suppression state surfaces in `GET /api/mills/overseers`.
