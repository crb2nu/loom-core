- **Mills intake: onboard repos and create projects from the HUD** (`cmd/loom-mills-operator/{handlers_projects,policy_edit}.go`, `pkg/mills/policy.go`, `internal/hud/domain/forge/`, `internal/hud/frontend` Projects panel + dialogs): Work → Projects is now the intake surface. `GET /api/mills/projects` lists every repo the operator knows (home, `cross_repo.demand_projects`, `intake.gitlab.projects`, the runtime registry) with a readiness verdict computed from the same policy accessors the reconciler and gates use, each blocker named (`cross_repo_disabled`, `not_in_demand`, `allow_bootstrapped_off`, `protected_paths_unknown`). `POST /api/mills/projects/onboard` registers an existing GitLab repo at runtime; the protected-paths resolver now treats runtime-registered repos as known under the same two-key gate that lets them source demand, so an onboarded repo inherits the global protected list instead of the fail-closed match-all that sent every run to human review. `POST /api/mills/projects/policy-mr` opens the gitops MR that writes the Git-policy half — anchored line insertions into `demand_projects`, `intake.gitlab.projects`, `protected_paths_per_repo`, `per_repo_overrides` that preserve every comment, plus the deployment `policy-checksum` bump — idempotent and fail-closed on a missing anchor. The new HUD `forge` domain resolves GitLab/GitHub identity from env or the operator's `glab`/`gh` logins (`GET /api/forge/auth`), lists groups and repos (`/api/forge/groups`, `/api/forge/repos`), creates a seeded GitLab project with a GitHub push mirror (`POST /api/forge/projects`, `dry_run` supported), and imports a GitHub repo into GitLab keeping GitHub as the mirror (`POST /api/forge/projects/import`). In the Projects panel: a forge identity bar beside the admin-token bar, **⊕ Onboard repo** (provider picker with per-row Mills status) and **＋ New project** (group, bucket-rule visibility, template, mirror, onboard; preview before create), readiness chips on every card, and a Mills section in the detail pane with blockers, pending Git-policy work, and the actions that clear them.
