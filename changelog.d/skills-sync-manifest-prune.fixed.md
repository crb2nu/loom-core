- `loom sync skills <target>` now prunes previously generated skill files for skills deleted from `skills-registry.yaml`: before writing the new `.loom-skills-manifest.json`, the generator diffs the prior manifest and removes stale files (and directories left file-free), so home dirs like `~/.claude/commands/` and `~/.codex/skills/` converge instead of accumulating orphaned bundles. Pruning is manifest-scoped — hosted-import and hand-authored skill directories are never touched.
