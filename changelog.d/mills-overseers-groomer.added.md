Mills Overseers (slice 1): supervisory-agent harness + Backlog Groomer. New `pkg/mills/overseer` package with a shared guarded-auto-act harness (policy-gated loop, per-tick/rolling-24h action caps from durable events, dry-run default ON, full audit trail in the events table) and a nil-safe LLM triage adapter over the operator's judge client. The groomer dedups queued backlog items (deterministic Jaccard ≥ threshold; gray-band pairs confidence-gated through an LLM verdict), flags zombie items, and demotes stale P0/P1 priorities — retiring duplicates to the new terminal `retired` backlog state. Policy: `overseers:` section (default-OFF, per-action-class `allow` flags). Store: `EventDAO.ListByActorSince` + the terminal `retired` backlog state (no schema migration — the audit read rides the existing `idx_events_occurred` index). API: `GET /api/mills/overseers`, `POST /api/mills/overseers/{agent}/pause|resume|tick`. Sentinel + foreman agents land in follow-up slices on the same harness.
