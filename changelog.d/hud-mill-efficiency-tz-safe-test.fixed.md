The mill-efficiency helper tests no longer depend on the machine's timezone. `firstPassYield` deliberately buckets runs by viewer-local midnights (the HUD's "today" tile means the viewer's today), but its tests pinned run timestamps as hardcoded UTC strings, so the bucket a run landed in shifted with `TZ`: west of UTC the "future" boundary probe fell into today's bucket (today became `0` instead of `undefined`), and east of UTC (e.g. UTC+12, where the injected noon-UTC `NOW` is already the next local day) the daily-yield and StartedAt-fallback cases shifted a full bucket. All `firstPassYield` inputs are now derived from the injected `NOW` via local-day helpers, with the window edges probed at exactly one millisecond outside local-midnight boundaries. The suite is verified green from UTC-11 through UTC+14 including a fractional-offset zone; the helper itself is unchanged.
