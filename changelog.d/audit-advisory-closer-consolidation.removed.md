Writing the consolidation test exposed that this variant had shipped broken: its title guard evaluated `startswith`/`endswith` against the whole issue object (jq `and` does not rethread `.title`), so any run whose listing contained a real digest title aborted with `startswith() requires string inputs` — dry-run included; the guard now pipes `.title` through the match. Removed: `scripts/audit-advisory-sweep.sh`, `scripts/bulk_close_audit_advisories.sh`, and `scripts/close_stale_audit_advisories.sh` (the last selected on an `audit_digest` label the producer contract never writes — digests are labeled `audit-digest` — and applied no author filter), plus their `tests/scripts/` harnesses, superseded by `tests/scripts/close-stale-audit-advisories_test.sh`, which also proves the per-issue label-then-close ordering against a mocked `glab`. `docs/MILLS.md` and `docs/runbook-audit-advisory-bulk-close.md` now point only at the canonical script (the MILLS.md cleanup section also moves below the factory-exhaust policy block it had split in two), and the unreleased `added` fragments for the removed variants are dropped so the folded changelog announces this tooling once.
